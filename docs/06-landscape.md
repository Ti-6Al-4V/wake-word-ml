# Ландшафт: как устроены голосовые агенты и готовые wake word решения

Зачем этот документ: прежде чем писать свою модель, надо понимать, как задачу
решают все остальные, и почему для русского слова на ESP32 готового решения нет.

---

## 1. Полный пайплайн голосового агента

Любой голосовой ассистент (Алиса, Alexa, DIY-проекты) — это цепочка из 5 этапов:

```
[1] Wake word      on-device, всегда включён     своя маленькая CNN
        │  "услышали триггер"
        ▼
[2] VAD            on-device, границы реплики     Silero VAD / WebRTC VAD / энергия
        │  "поняли где речь началась и кончилась"
        ▼
[3] STT            облако или сервер              Whisper / faster-whisper / Deepgram
        │  аудио → текст
        ▼
[4] LLM            облако или сервер              GPT / Qwen / локальная модель
        │  понимание + ответ (+ vision, если пришло фото)
        ▼
[5] TTS            сервер или on-device           Kokoro / Piper / API
        текст → голос
```

Разделение труда:

| Этап | Где работает | Почему |
|------|--------------|--------|
| Wake word | Только устройство | Всегда включён, батарея, приватность, офлайн |
| VAD | Устройство | То же самое |
| STT/LLM/TTS | Сервер | Модели на сотни MB–GB, в ESP32 не влезут |

Ключевой вывод: **wake word — единственная часть, которую делают на
микроконтроллере**. Всё остальное в CapAI уже уходит на сервер по WebSocket.

## 2. Требования к wake word движку

| Параметр | Значение | Комментарий |
|----------|----------|-------------|
| Размер модели | <1 MB, лучше <100 KB | Flash + RAM |
| Потребление | мВт | Работает всегда, от батареи |
| Задержка детекции | <500 мс | Иначе ощущение лага |
| False reject (пропуск слова) | <5% | Хуже раздражает |
| False accept (ложная тревога) | <0.5 в час | **Главная метрика** |

Ложная тревога важнее точности: кепка, которая просыпается от сериала
на фоне — провал, даже если распознаёт слово в 99% случаев.

## 3. Готовые решения

### 3.1 Picovoice Porcupine

Коммерческий движок, де-факто стандарт в индустрии.

**Как работает:**
- Движок (runtime) — закрытая компактная CNN, написана на C, работает на
  Arm Cortex-M, Raspberry Pi, всех мобильных и десктопных платформах.
- Кастомное слово обучается через Picovoice Console методом **transfer
  learning**: вводишь фразу текстом → их большая базовая модель за секунды
  дообучается под неё → скачиваешь файл модели `.ppn` (~сотни KB).
- В рантайме: `pv_porcupine_process(handle, pcm_frame, &keyword_index)` —
  отдаёшь кадры PCM 16-bit, получаешь индекс сработавшего слова.
- Один параметр настройки: `sensitivity` [0..1] — баланс между пропусками
  и ложными тревогами.
- AccessKey обязателен (бесплатный tier есть, лимиты на использование).

**Что решает:** production wake word без своего ML — ввёл слово, скачал
модель, деплой. Так делают тысячи продуктов.

**Русский язык: ВЫПИЛЕН.**
- В официальной документации Porcupine русский отсутствует в списке языков
  (есть en, fr, de, it, ja, ko, zh, pt, es).
- Issue [Picovoice/porcupine#1429](https://github.com/Picovoice/porcupine/issues/1429),
  июнь 2025, ответ Picovoice: *"Unfortunately, support for Russian has been
  removed. If you are interested in engaging with us commercially, please
  contact sales."*
- Библиотека `Porcupine_RU` на PlatformIO и репо
  [Picovoice/porcupine-arduino-ru](https://github.com/Picovoice/porcupine-arduino-ru)
  — это легаси: рантайм работает, пресеты слов остались, но **обучить новое
  русское слово в консоли нельзя**. Для слова "гермес" бесполезно.

### 3.2 openWakeWord

Открытый (Apache-2.0), десктоп/Raspberry Pi ориентированный.

- Обучение на синтетике через TTS, архитектура — embeddings + маленький классификатор.
- Заявлено: только английский (TTS-движки для генерации данных английские).
- На Cortex-M официально не нацелен. Для кепки не подходит.

### 3.3 microWakeWord (Open Home Foundation / ESPHome)

Открытый (Apache-2.0), **самый близкий к нашему случаю**.

- Создан Kevin Ahrendt (ESPHome wake word). Модели — TFLite Micro,
  архитектура MixConv из статьи Google "Streaming Keyword Spotting on
  Mobile Devices", стриминговый inference каждые 30 мс.
- Обучение: генерация позитивов через **Piper sample generator** (Piper TTS
  имеет русские голоса) + аугментации + негативы → тренировка в Colab-ноутбуке.
- Валидация заточена под false accepts/hour на "ambient" записях — правильная
  методология, стоит скопировать.
- Минусы: авторы честно пишут "training a model that works well is still
  very difficult", early release. Плюс TFLite Micro рантайм (нам не нужен,
  у нас ручной inference).

**Чем полезен нам:** не как зависимость, а как **методология** — их подход к
данным (много TTS-голосов, ambient-негативы, метрика ложных тревог) — это то,
что отличает рабочую модель от игрушки.

### 3.4 esp-sr WakeNet (Espressif)

Родной стек для ESP32.

- WakeNet9/9s — готовые слова ("Hi, Lexin", "Alexa" и пр.), оптимизированы
  под чипы, минимальный footprint.
- Кастомные слова: через их TTS-пайплайн. TTS Pipeline V3 (апрель 2026)
  обучает wake words на китайском, английском, японском, французском.
  Русский — в списке "planned support".
- Пока русского нет — для "гермес" не подходит.

### Итог по готовым решениям

| Решение | Русский кастом на ESP32 | Статус |
|---------|------------------------|--------|
| Porcupine | Нет, поддержка удалена (2025) | Только легаси-пресеты |
| openWakeWord | Нет, английский | Десктоп |
| microWakeWord | Теоретически да (Piper RU TTS) | Сложно, early release |
| esp-sr WakeNet | Нет, "planned" | Только пресеты |

**Вывод: готового turnkey-решения для кастомного русского wake word на
ESP32 не существует. Своя модель — не упрямство, а единственный полностью
контролируемый путь. Плюс — полное понимание под капотом.**

## 4. Что берём из чужого опыта

1. **Метрика качества — false accepts в час**, а не accuracy (microWakeWord).
2. **Много разных TTS-голосов** для позитивов, а не 2 голоса (Porcupine
   обучает на огромном банке голосов; microWakeWord — десятки Piper-голосов).
3. **Ambient-негативы**: музыка, подкасты, уличный шум как отдельный
   валидационный набор (microWakeWord).
4. **Двухступенчатая схема**: дешёвый гейт (энергия/простой VAD) → CNN.
   Экономия батареи в always-on режиме.
5. **Слово выбирается длинное и фонетически редкое** (Picovoice tips):
   "гермес" (2 слога, 6 фонем, редкое в обиходе) — нормальный выбор.
