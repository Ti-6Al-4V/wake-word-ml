Скопируй в `experiments/YYYY-MM-DD-name.md`. Аудио и веса храни отдельно;
не добавляй их в Git. Для артефактов можно использовать `models/runs/<id>/`.

- Гипотеза и прогноз **до запуска**:
- Единственное меняемое условие:
- Контрольный прогон:
- Commit кода (`git rev-parse HEAD`), незакоммиченный diff:
- Версии Rust/Burn, backend, устройство:
- Версия датасета, список файлов и SHA-256, метки, source/session/speaker:
- Списки train/val/test; критерий группировки; общие фоны/TTS-источники:
- Предобработка, признаки, аугментации (в каких сплитах):
- Seed и гиперпараметры, точная команда:
- Файлы весов, логов, диагностических примеров:
- Правило выбора чекпоинта, порога, K, cooldown:
- Что измерено: loss, FP/FN, event recall, FA/h, задержка, RAM/время:

## Чек-лист честного сравнения

- [ ] Val фиксирован, test не использован для выбора.
- [ ] Все производные исходника находятся вместе; проверены сессии/дикторы.
- [ ] Сохранён сам checkpoint, а не только CSV.
- [ ] Качество на обучающих данных не названо обобщением.
- [ ] План, предположение и измеренный результат явно различены.
- [ ] Новая версия данных не сравнивается со старой как «сменили только модель».
