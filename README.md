# Wake Word ML

Обучение custom wake word модели для ESP32-S3 на Rust.

Цель: нейросеть, которая офлайн на микроконтроллере узнаёт слово «Гермес» от любого человека и которую можно распространять. Понять, как это работает под капотом. Внедрить в CapAI.

## Стек

- **Язык:** Rust
- **Обучение:** [burn](https://github.com/tracel-ai/burn) — Rust ML framework
- **Аудио:** `rustfft`, `hound` (WAV I/O), ручной MFCC (`src/mfcc.rs`)
- **Деплой:** ручной C++ CNN inference на ESP32-S3 (план: модель 4425 параметров)
- **Интеграция:** CapAI firmware

## Состояние (2026-09-29)

- Работает: запись, preprocess, MFCC, аугментация обоих классов, CNN,
  обучение, оценка клипов, FA/h на потоке, сплит по дикторам с holdout-test.
- Обученной модели нет; checkpoint до 2026-09-21 несовместим с текущими
  признаками (CMVN в f64) и удалён.
- Датасет пока не годится для цели «любой голос»: позитивы — один живой
  диктор и два голоса Edge TTS, негативов своим микрофоном нет, holdout
  не собран. Что делать — этап 4 плана.
- Не реализовано: генератор синтетических дикторов, экспорт весов,
  C++/ESP32, событийная разметка. Качество на устройстве не измерено.

## Почему своя модель

Главная причина — научиться строить и проверять систему целиком, управляя
данными, frontend, моделью и inference. Это не утверждение, что готовых
альтернатив нет. [Обзор движков](docs/06-landscape.md) — справочный снимок;
актуальную поддержку языка/устройства нужно проверять перед выбором.

## Пайплайн

```
"Гермес" (голос)
    │
    ▼
INMP441 → I2S → PCM 16kHz 16-bit
    │
    ▼
MFCC: извлечение признаков (20 коэффициентов × 40 кадров, окно 1.2с, CMVN)
    │
    ▼
CNN (4425 параметров, 18 KB, бинарные веса)
    │
    ▼
логит → score → порог + подтверждение + cooldown → wake word / не wake word
    │
    ▼
Если wake → CapAI просыпается
```
